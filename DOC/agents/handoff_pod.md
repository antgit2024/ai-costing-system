## POD/印刷自动化 Agent 接力包（POD Agent）

> 目标：后续关于“个性化定制（POD）→ 单裁片PDF → RIP自动拼版 → 自动下发打印/切割 → 回传ERP”的所有讨论与实施，都由本 Agent 作为接力入口。  
> 口径：本 Agent 只做 **方案收口/实施拆解/接口契约/风险护栏**；不在未确认工厂参数时做过度细化。

---

### 1) 当前已定死的事实（不要再重复争论）

- **先印布**（不是成品印）：必须有裁片模板（出血/安全区/缝边吃进）
- **工厂要求**：需要裁切线/定位标（格式不限）
- **先不依赖 AI**（AI 作为 Phase1 增强：素材生成/扩图/高清化/审核）
- **工厂能力**：
  - 有 **RIP 软件**，且支持**自动拼版**
  - 有 **切割设备**
- **大幅面常用 DPI**：150
- **长宽比差异（长方→正方等）**：允许人工参与（预览+裁剪框微调），不要试图 Phase0 全自动重构图
- **职责边界**：系统侧生成“单裁片 PDF（标准化，含矢量标记）”；拼版与最终栅格化优先交给 RIP

### 3) 讨论时的关键约束（避免跑偏）

- **PDF 不等于超大位图**：PDF 推荐“嵌入图像对象 + 叠加矢量裁切线/定位标/文字”，最终栅格化交给 RIP
- **Web 不做重活**：浏览器只做轻量编辑与预览；生产文件生成在后端/工厂打印服务器（异步 job + 对象存储）
- **安全与稳**：
  - 生产包下载必须受控（签名URL/工厂账号鉴权）
  - 产物快照化（input hash + template + output hash）可重跑/可追溯

---

### 4) 后续需要工厂确认的“参数清单”（讨论推进的输入）

- RIP 接单方式：热文件夹/队列 API/命令行（可混用）
- 切割线要求：PDF 矢量层 vs SVG/DXF
- 定位标规范：样式/尺寸/颜色/位置
- 拼版分组规则：同 ICC profile/同面料/同工艺/同机台参数
