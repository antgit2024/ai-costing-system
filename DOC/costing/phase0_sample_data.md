## 2. Phase0 验收清单

1. **导入验证**
   - 物料：字段 `material_code`, `material_name`, `unit`, `latest_price`, `supplier_name` 与本地 `materials` 表一一对应。
   - 工序：校验 `process_code`, `process_name`, `default_duration`, `loss_rate` 等字段，确认物料/人工引用完整。
   - 产品模型：导入模型、模型-工序映射以及模型-物料/人工明细。
2. **计算验证**
   - 选取至少 3 个模型（尺寸 0.5m/1m/1.5m），验证标准尺寸与实际尺寸计算一致。
   - 触发面积/周长变体（例如 >1.5㎡ 切换厚板、>4m 加龙骨）。
3. **SKU 绑定验证**
   - 在样本中选择 2 个 SKU，完成 AI/人工确认绑定 → 修改 SKU 标题后再次计算，确保只按 SKU ID。
4. **审计与导出**
   - 克隆/审批/导出流程需生成 `audit_logs` 记录（即便 Audit API 尚未放通，也需保存 JSON 结果）。
5. **记录**
   - 将导入/计算/导出结果、关键 job/trace/favorite ID 写入 `DOC/agents/task_log.md`。

> 后续批量导入之前，需基于此清单完成一次样本验收，并在 QA 文档附上截图/日志。
