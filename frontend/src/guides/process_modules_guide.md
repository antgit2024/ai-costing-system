## 1. 背景与定位

- “工艺模块（Process Module）”用于封装一组可复用的生产步骤，包含 **物料组**（BOM 行）、**工序组**（工时/人工）以及 **可选的虚拟物料引用**。
- 模块是产品模型与订单计算的共享单元，任何模型引用某个模块时都会自动继承其中的物料/工序/虚拟引用，避免重复维护。
- 模块需要具备版本与发布能力，确保在被多个模型使用时可以受控更新。

## 2. 列表视图

路径：`/costing/process-modules`

| 列/功能 | 说明 |
| --- | --- |
| 搜索框 | 支持按模块编码/名称模糊查询 |
| 筛选器 | 状态（草稿/评审中/已发布/已停用）、创建人、最近更新时间 |
| 列 | 模块编码、名称、版本号、状态、绑定数量（被引用的模型数）、最近发布人/时间 |
| 操作 | 查看/编辑、复制为新版本、发布、停用、查看引用（弹窗列出使用该模块的模型） |

> 列表底部提供“导出模块清单”按钮，导出字段与 `process_modules` 表对齐，用于发送给外部供应商或进行离线评审。

## 3. 详情 / 编辑器

### 3.1 基础信息区

- 字段：模块编码、名称、所属类型（加工/组装/包装）、描述、标签、状态、版本号。
- 状态提示：当模块已发布且被引用时，顶部显示 `Published v1 • 被 12 个模型使用`，并提供“创建新版本”按钮。
- 单位说明：模块层不定义单位，具体耗用单位由子级物料/工序决定。

### 3.2 物料组（BOM 区）

| 字段 | 说明 |
| --- | --- |
| 物料 | 支持搜索真实物料或选择虚拟物料；选择虚拟物料时在行右侧显示“虚拟 · 套件”徽标 |
| 数量/口径 | 录入 `quantity` + 可选 `calculation_method`（count/perimeter/area/length/width/height/custom），默认 count |
| 单位 | 自动带出真实物料单位；若引用虚拟物料则展示“套” |
| 损耗率 | 0–100% |
| 描述 | 可写入 `metadata.local_description`，在真实物料抽屉中同步展示 |
| 虚拟引用 | 当行引用虚拟物料时，展示 `virtual_code + ratio` 信息，并允许跳转至虚拟物料详情 |

其他配置：
- 行操作：复制、删除、上/下移动。
- 支持批量导入（Excel 模板字段与 `process_materials` 对齐）。

### 3.3 工序组（工时区）

- 字段：工序类型、工时（基于数量/面积/长度等）、计价方式、参考成本、操作说明。
- 允许引用虚拟工序（如“上门安装服务”）并附加 `calculation_method`。

### 3.4 发布 / 版本历史

- 详情页右上角提供“提交评审”“发布”“退回”按钮；仅审批通过的草稿可以发布。
- 发布成功后生成 `version_no`，并将快照写入 `process_module_versions`，供历史追溯。
- “版本历史”抽屉展示所有版本，支持对比物料/工序差异，以及“基于 vX 创建新版本”。

### 3.5 模块引用提示

- 页面右栏展示“双向引用”：
  - **被引用列表**：列出所有使用该模块的产品模型，包含模型状态、最近发布时间，可点击跳转。
  - **模块内引用**：在物料列表中标记虚拟物料引用，点击可打开虚拟物料抽屉。

### 3.6 盘点与发布校验

- 若模块包含虚拟物料，顶部 banner 提示“请在产品模型或盘点接口传入 calculation_method/usage_context，否则无法折算至真实物料”。
- 发布前自动校验：真实物料必须启用且单位存在、虚拟物料的 binding 配置完整、数量/损耗数值合法。校验失败时在对应行给出错误并阻止发布。

## 4. 接口规范

- `GET /process-modules` 默认返回最新发布版本；带 `?include=draft=1` 时附带草稿。
- `POST /process-modules/{id}/versions` 创建新版本；随后使用 `PATCH /process-modules/{version_id}` 编辑。
- 物料/工序响应统一附带 `source_type`（real/virtual/module），便于前端展示徽标。
