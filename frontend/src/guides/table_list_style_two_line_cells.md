## 列表页样式规范（参考：工序管理列表）

### 目标
- 列表页以“信息密度高 + 可扫读”为优先
- 单元格采用“两行结构”：第一行主信息，第二行口径/补充信息
- 统一操作列按钮风格，避免文本按钮造成视觉噪音

## 版式结构（推荐列）

### 1）编码
- **列名**：编码
- **样式**：使用 `Text code`
- **宽度建议**：80 左右（窄）

### 2）工序（合并信息列，二行）
- **列名**：工序
- **第一行**：名称（加粗，ellipsis）
- **第二行**：口径文本 + 标签（胶囊 Tag）
  - 口径文本固定格式：
    - `分类：{category}；计量类型：{chargingModeLabel}；单位：{unit}`
  - 标签：右侧展示 0～3 个，超出显示 `+N`
- **宽度建议**：260 左右

### 3）类型/工时（或 类型/单价，二行）
- **列名**：类型/工时
- **规则：只显示当前生效计价类型的一套信息（完整且不混杂）**
  - 若当前为 **计时**：
    - 第一行：`计时`
    - 第二行：`基础工时：{base}分钟+单位工时：{unit}分钟`
  - 若当前为 **计件**：
    - 第一行：`计件`
    - 第二行：`{pieceRate}元/件`
- **宽度建议**：170 左右

### 4）描述（重点）
- **列名**：描述
- **展示**：两行省略（ellipsis rows=2 + tooltip）
- **宽度建议**：比默认描述列加宽约 1/2（例如 390 左右）

### 5）更新时间
- **格式**：`YYYY-MM-DD HH:mm`
- **宽度建议**：150 左右

### 6）操作（缩窄）
- **按钮风格**：图标按钮 + Tooltip + **带边框**（不要 `type="text"`）
- **宽度建议**：160 左右（比常规操作列更窄）
- **一致性**：查看/编辑/AI/复制/停用/启用/删除统一“有边框图标按钮”风格

## 组件/实现要点（可复制）

### 两行单元格
- 使用 `<div style={{ lineHeight: 1.25 }}>`
- 第二行与第一行间距：`marginTop: 4`

### 描述两行省略
- 使用 `Typography.Paragraph`
- 关键参数：`ellipsis={{ rows: 2, tooltip: value || '-' }}`

### 胶囊标签（Tag）
- 关键样式：
  - `borderRadius: 999`
  - `padding: '0 6px'`
  - `fontSize: 12`
  - `lineHeight: '18px'`
- 容器：`<Space size={6} wrap>`

### 单位推导口径
- “单位”不让用户填，按计量类型（charging_mode）自动推导：
  - 面积 → 平米
  - 周长/宽度/高度/长边/短边 → 米
  - 数量/固定/兜底 → 个
