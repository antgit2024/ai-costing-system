# 提炼：发货单.xlsx（表头/关键列，基于xlsx-xml解析）

- 源文件：`DOC/基础表单/发货单.xlsx`
- 目的：确认“发货↔售后强关联键”列位与口径

## 1) 表头（Row 1，节选关键字段）

> 该文件字段很多，此处仅列出与核算/对账/关联强相关的列（完整表头可按需再提炼）。

| 列 | 字段名（原始） | 备注（口径） |
|---|---|---|
| S | 销售渠道 | channel |
| V | 原始单号 | **order_no（网店订单号/天猫订单编号）** |
| W | 货品编号 | product_code（可用于弱关联/展示） |
| X | 货品名称 | product_name（展示） |
| AA | 货品条码 | **sku_code（系统 SKU 主键）** |
| AF | 金额 | revenue_amount |
| Z | 数量 | qty |
| H | 完成时间 | completed_at（归属期口径建议用它） |
| AI | 交易规格 | **spec_text（以发货侧为准；售后“规格”可能过时）** |
| AK | 商品链接ID | **product_link_id（强关联键之一）** |
| I/J | 物流公司/物流单号 | 物流追溯（可选） |

## 2) 结论：强关联键

发货单侧可用于与售后单强关联的组合键：
- `原始单号(V)` + `商品链接ID(AK)` + `货品条码(AA)`
