# 真实物料（物料主数据）新建/维护指南（建议稿）

> 说明：该指南用于帮助你在“真实物料/物料主数据”面板正确维护成本参数与计量口径。

---

## 1. 先确认：这是“真实物料”还是“虚拟物料”？
- **真实物料**：有明确采购单位、供应商单价、可入库。
- **虚拟物料**：配方/套件/占位符，用于工艺/模型层组合与替换。

## 2. 核心字段怎么填
- **物料编码/名称**：保持稳定，不要用备注区分。
- **单位（采购单位/BOM单位/库存单位）**：优先以 BOM 口径作为核算口径。
- **单位换算**：
  - 采购→BOM：`conversion_purchase_to_bom`
  - BOM→库存：`conversion_bom_to_inventory`
- **BOM 单价**：用于核算（若未直接维护，会尝试由采购单价/换算推算）。
- **计量口径（calculation_method）**：决定该物料的“计价量”如何从宽/高/数量计算（count/area/perimeter/width/height）。

## 3. 常见错误（避免）
- **只填采购单价不填换算**：会导致 BOM 单价推算错误。
- **计量口径选错**：会导致产品模型预览计算不可信。
- **把工艺参数写进物料备注**：备注只用于说明，不应当承载可计算规则。

## 4. 验收（自检）
- 物料列表能正确显示单位/单价
- 进入产品模型预览：该物料在不同尺寸下，计价量变化符合预期
