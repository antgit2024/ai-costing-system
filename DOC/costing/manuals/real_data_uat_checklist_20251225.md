## 真实数据实测验收清单（线上 47.99.89.206）

- 最近校对（北京时间 GMT+8）：2025-12-25

### 目标

- 在生产环境 `47.99.89.206` 使用真实文件跑通链条，覆盖约 **200 行**，并形成可复盘的验收记录。
- 成本口径：**物料成本 + 工序成本 + 制造费用（30%）= 合计成本**（阶段性固定，后续再讨论制造费取值与口径升级）。

### 入口页面

- SKU 主档工作台：`/costing/sku-master`
- 发货监控（预览→执行→快照）：`/costing/shipments`
- 标准模型（模型清单/工序/识别关键词）：`/costing/standard-models`
- 物料主数据（真实物料单价/换算、虚拟物料绑定）：`/costing/materials`、`/costing/virtual-materials`

## A. 先决条件（必须）

### A1 真实物料主数据可计价

- **验收点**：
  - 真实物料 `unit_price` 与 `conversion_purchase_to_bom` 可用（或 `metadata.bom_unit_price` 已有值）。
  - BOM 预览中“物料行”有 `BOM单价/行成本`（至少核心物料有）。

### A2 虚拟物料绑定真实物料（用于扣库清单展开）

- **验收点**：
  - 虚拟物料（VM）有绑定真实物料集合，并填好 `quantity_ratio` 与 `loss_rate`（如有）。
  - BOM 预览/快照里“扣库清单（真实物料）”Tab 有数据，且与业务预期一致。

### A3 标准模型版本规则

- **验收点**：
  - 每个模型只有一个在线发布 `standard` 版本（避免 SKU 绑定歧义）。
  - 模型工序行已配置计价字段（`cost_type`/`rate_per_minute` 或 `piece_rate` 等），否则工序成本会是 0 或有 warnings。

## B. 实测流程（从 0 到 200 行）

### B1 SKU 主档导入（真实平台商品列表）

- **动作**：上传你准备的“平台商品列表”文件到 `/costing/sku-master` 的导入入口。
- **验收点**：
  - 可搜索 SKU（条码）并查看 `spec_text/product_name/channel` 等字段是否齐全。
  - SKU 绑定状态正确（未绑定/已绑定）。

### B2 SKU 绑定（确保发货行可执行）

- **动作**：
  - 用“自动绑定预览→执行”（基于型号识别关键词）先提升覆盖率；
  - 对剩余核心 SKU 用手工绑定补齐。
- **验收点**：
  - 目标：将本次发货单涉及的 SKU 尽量绑定到已发布标准版本（否则发货预览会出现 `SKU_NOT_BOUND`）。

### B3 发货单导入：预览→执行

- **动作**：在 `/costing/shipments` 上传真实发货单文件，点 **预览**，确认文件名正确，再点 **执行**。
- **验收点（预览）**：
  - `可执行` 行数尽量接近 200（或至少可执行的那部分可闭环）。
  - 未绑定行/缺规格行/缺条码行原因清晰。
- **验收点（执行）**：
  - 执行后“发货批次列表”新增批次，文件名对应本次上传。
  - “BOM 快照”列表出现记录。

### B4 BOM 快照抽屉核对（关键验收）

- **动作**：在 BOM 快照列表点“查看”，打开抽屉。
- **验收点**：
  - Tabs：**汇总 / 物料 / 扣库清单（真实物料） / 工序 / Trace**
  - 汇总：能看到合计成本、物料成本、工序成本、制造费 30%、单位成本。
  - 物料：可能多为虚拟物料（可接受）。
  - 扣库清单：必须是 **真实物料**（用于扣库存/盘点/盈亏）。
  - 工序：应有明细行（如模型配置了工序），且计入成本。

## C. 常见问题定位

- **发货预览可执行很少**：
  - 多数是 `SKU_NOT_BOUND` → 回到 SKU 绑定工作台补齐绑定。
- **工序为 0**：
  - 模型版本未配置工序行，或工序缺少计价字段 → 去标准模型编辑工序行。
- **扣库清单为空**：
  - 虚拟物料未绑定真实物料 → 去虚拟物料绑定页补齐 bindings。
  - 历史快照缺字段 → 用快照列表“回填”按钮重算。
